# Solar Drift — web-sdk app

A port of Solar Drift onto the **StakeEngine `web-sdk`** (Svelte 5 + PixiJS 8 + TypeScript),
based on the `ways` template. This folder is a web-sdk **game app** — it builds inside the
web-sdk monorepo, which supplies the shared packages (`pixi-svelte`, `utils-book`,
`components-ui-pixi`, …).

## What this port contains

- **`src/game/config.ts`** — Solar Drift's math identity: 5×4 / 1024 ways, the Solar Drift
  paytable mapped onto the template symbol keys, `base` (1×) and `bonus` (100×) bet modes,
  96.20% RTP.
- **`src/game/constants.ts`** — board geometry set to 5 reels × 4 rows.
- **`src/stories/data/{base,bonus}_books.ts`** — real Solar Drift outcomes in the web-sdk
  bookEvent format (`reveal → winInfo → setTotalWin → setWin → finalWin`, and
  free-spin sessions with `updateFreeSpin` / `freeSpinEnd`). Generated by
  `solar-drift-math/generate_websdk.js` from the same math as the RGS publication.
- Everything else (state machine, book→event engine, board/free-spin components, UI) is the
  web-sdk template, reused as-is.

Symbol key mapping (template key → Solar Drift symbol): `W` Cosmic Wild · `S` Black Hole
Scatter · `H5` Singularity · `H1` Solar Commander · `H2` Energy Scientist · `H3` Solar Core ·
`H4` Drift Ship/Plasma Planet · `M` Energy Core · `L1` A · `L2` K · `L3` Q · `L4` J/10.

## Build it (inside the web-sdk monorepo)

```bash
nvm install 22.16.0
npm install -g pnpm@10.5.0
git clone https://github.com/StakeEngine/web-sdk.git
cp -r solar-drift web-sdk/apps/solar-drift        # this folder
cd web-sdk
pnpm install
pnpm run build --filter=solar-drift               # -> apps/solar-drift/build/ (index.html + client)
pnpm run dev --filter=solar-drift                 # local dev server
pnpm run storybook --filter=solar-drift           # browse books/bookEvents
```

The production build (`build/index.html` + `client/`) is what you upload to the Stake Engine
dashboard. This port has been verified to build with `pnpm run build --filter=solar-drift`.

## Remaining work (art & polish)

This port nails the **game logic, math identity, board, bet modes, and book/event wiring**.
It deliberately does **not** include bespoke art — it inherits the template's asset slots.
To finish the visual skin:

1. Drop Solar Drift art into `static/assets/` and repoint `src/game/assets.ts`.
   The template uses **Spine** animations + bitmap fonts for win/scatter/wild states; Solar
   Drift ships flat PNGs, so set those symbol states to `type: 'sprite'` in
   `src/game/constants.ts` (`SYMBOL_INFO_MAP`) and provide the PNGs.
2. Replace background, free-spins intro/outro, transition and big-win assets, and the audio
   sprite (`static/assets/audio/sounds.json`).
3. Re-tune `bookEventHandlerMap.ts` sound/animation cues to taste.

Until then the game runs on web-sdk with Solar Drift's math and the template's placeholder
visuals.
